# 🎧 BOAT Electronics

A modern and responsive **electronics e-commerce frontend** built using **React.js and Vite**.

This project provides a user-friendly shopping experience for browsing electronics products, viewing product details, managing a wishlist, and adding products to a shopping cart.

## 🚀 Features

* 🏠 Home page with hero section
* 📦 Products listing
* 🔍 Product search
* 🏷️ Category filtering
* 📄 Product details page
* ❤️ Wishlist functionality
* 🛒 Shopping cart
* ➕ Increase product quantity
* ➖ Decrease product quantity
* 🗑️ Remove products from cart
* 💰 Automatic cart total calculation
* 🔐 Login page
* 📝 Signup page with validation
* ℹ️ About page
* 📞 Contact page
* 🌙 Dark / Light mode
* ✨ Page transition animations
* 💀 Skeleton loading
* 📱 Responsive design
* 💻 Desktop, tablet and mobile support

## 🛠️ Technologies Used

* React.js
* Vite
* JavaScript
* HTML5
* CSS3
* React Router
* React Context API

## ▶️ How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/dhanushbabu0118/Electronics.git
```

### 2. Open the project

```bash
cd Electronics
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open the application

Open the local URL shown in the terminal, usually:

```text
http://localhost:5173
```
